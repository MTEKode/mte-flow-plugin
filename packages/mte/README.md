# @mtekode/mte

MTE Flow engine (bin `mte`): memory MCP server, check runner, deploy-check, guard and installer. Node >= 24.

Install from the GitHub release tarball (not published to the npm registry):

```sh
npm i -g https://github.com/MTEKode/mte-flow-plugin/releases/download/mte-v0.8.8/mtekode-mte-0.8.8.tgz
```

From a checkout: `cd packages/mte && npm run build && npm link`. See the repository README for commands.
